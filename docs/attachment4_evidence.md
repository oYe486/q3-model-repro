## 定位与核验方法

先以新模型的完整模态 Shapley 值决定“解释主模态”，融合门控选择另存。对每个可用模态的有效对齐位置扫描局部遮挡窗口，按原预测类别边际下降排序；窗口的分数、翻类及决策支持均由**同一冻结模型**重算。文本窗口用同款 BERT fast tokenizer 的偏移量映射到 `raw_text` 字符区间，逐字校验原文。音频和视觉窗口不把特征索引线性缩放为时间：从 MP4 解码音轨，用独立的 Whisper `base.en` 生成逐词时间，仅在原文与 ASR 的对应词连续且完全匹配、且全样本文本—音轨匹配率不低于 `0.70` 时给出原视频秒数候选；低匹配样本一律保留为 `feature_only`。视觉再在该时段实际解码一个帧，记录真实读取的帧号与播放时间。视频时长和可用帧范围以**顺序解码所得**为准，不信任容器报告的帧数。所有位置记录均通过 `EvidenceLocation` 契约；音视频因缺少原始特征提取映射，状态仍为 `media_candidate`，不标为 `media_verified`。

20条样本的预测分数、Shapley 值、主局部遮挡效应和位置均已独立回放复核。主证据为18条精确原文片段、2条音频候选时段；三分类分布负／中／正为 `8/4/8`。首位音频局部证据有 `15/20` 条获得逐词时间候选；视觉在可用样本中有 `14` 条首位证据取得实际帧。候选帧总览已逐格目视检查，均来自对应视频内容，但**画面看起来合理**不能证明给定视觉特征行正是从该帧提取，故仍保留候选状态。现行15项单元测试和全部20条算法回放核验通过。

## 论文中的错误归因与逐样本限制

附件4没有真实情感标签，以下只能称为**输入缺陷或证据定位的潜在错误来源**，不能直接写成“模型分类错误由此造成”。逐样本 JSON 的 `error_attribution` 保存结构化标记，汇总 JSON 列出对应样本；原始 PKL 和 MP4 未被改动。

| ID | 可复核现象 | 归因层级 | 对结论的限制 |
|---|---|---|---|
| `13` | 对齐视觉特征在全部有效词位置为零，而 MP4 有可解码画面 | 提供的对齐视觉特征缺失；不是模型凭空漏检画面 | 模型屏蔽该视觉流，不得声称模型依据某个视觉关键帧。 |
| `07`、`18` | 原文分别为65、59个 BERT token，模型只接收50个 | 模型输入长度限制；不是原文错误 | 被截断的后段未参与预测，证据只能取自实际建模前缀。 |
| `15` | 用户人工听审确认 MP4 主要讲述前一段，结尾才说到“However”；原文则从“However”起并继续后文，ASR逐词匹配率仅 `0.235` | 提供的原文与媒体片段覆盖范围不一致 | 文本证据仅对应 PKL 的 `raw_text`；音频时段和视觉帧映射全部拦截为 `feature_only`，不能声称已在视频中定位后续原文。 |

另有16条 MP4 的容器标称帧数高于实际可解码帧数，最明显的是 `20`（标称约18.70秒，实际解码约10.93秒）。这是媒体元数据质量问题；此前推理代码信任标称帧数，属于证据流程缺陷。现已改为逐帧解码测量，20条中没有实际解码音视频结束时间差超过0.25秒的样本；这只消除了伪时长警告，不等于证明逐帧音画同步或特征行来源。

- `01` 的主模态排序间隔较弱，模型标记 `main_uncertain=true`。
- `13` 的对齐视觉特征全零，不能给该样本编造视觉关键帧；其音频主证据 `7.56–8.54s` 是候选，局部决策支持仅 `0.0098`。
- `19` 的音频主证据 `11.68–12.78s` 是候选，局部决策支持仅 `0.0084`。两条音频主模态样本都可能依靠较分散的语音信息，不能把一个短窗口表述为全部证据。
- `15` 的原文与当前 MP4 音轨逐词匹配率只有 `0.24`；用户已确认音轨主要为前一段内容。其文本主证据仍可精确回指**提供的原文**，但不能据此认定原视频讲出了该片段；音视频候选映射已全部拦截。
- `07`、`18` 的原文超过模型50-token上限；证据只能来自实际建模的前缀。
- `02`、`03`、`04`、`06`–`12`、`14`、`16`–`20` 的容器帧数高估可解码帧数；不能把标称时长与音频时长的差当作真实音视频不同步。现在只以可解码视频时长限制候选帧。
- 个别模态首位局部证据因ASR词不连续而保持 `feature_only`；具体ID和原因在逐样本JSON的 `warnings` 及 `time_mapping_note`。即便模型主证据已定位为文本，也不能把其他模态未映射的窗口说成原始语音或视觉证据。

**结论：**问题3所需的逐样本强度、类别、三模态有符号作用、主模态及关键证据接口现已贯通，20条附件4数据均有可复算的主证据记录。但音视频时间／帧与原始特征行之间尚缺采集/提取时的权威对应表；目前只能提交有来源、有时间/帧号、有质量标记的候选定位，不能声称全部媒体证据已严格验证。若竞赛要求“精确对应原始语音时段或视觉关键帧”而非候选，仍需取得原特征提取时间戳或按相同流程重提取并留存映射，再人工逐条复核。
