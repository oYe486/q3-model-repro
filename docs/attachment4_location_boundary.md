# 附件4证据定位结论与提交措辞

本说明对应当前冻结模型及 `outputs/attachment4/predictions_20.jsonl`。附件4的20条对齐版样本只用于无标签推理。证据位置有三个不同层级，论文、解释卡和提交结果应保留原始状态字段，不把它们合并称为“已定位到原视频”。

| 状态 | 可以作出的结论 | 不应作出的结论 |
| --- | --- | --- |
| `text_exact` | 模型使用的文本窗口可由 BERT 偏移量逐字回指附件4特征文件中的 `raw_text` 字符区间。 | 该文字一定出现在配套 MP4 的音轨中，或其口播时间已经确定。 |
| `media_candidate` | 原文与 MP4 音轨的 ASR 词连续匹配后，得到候选音频时段；视觉候选还记录了在该时段实际解码的帧号和播放时间。 | 原始音频／视觉特征行确由该时段或该帧提取。 |
| `feature_only` | 仅能复核模型输入中的特征位置及局部遮挡效应。 | 已定位到原始语音时段或视觉关键帧。 |

当前没有 `media_verified` 记录。附件4的 PKL 缺少原始特征行到媒体时间、帧的提取映射，因此人工回看候选视频内容也不能单独证明特征来源。若要求严格的原始媒体对应关系，需要取得特征提取时的时间戳／帧索引，或依照同一提取流程重建映射并逐条复核；在此之前保持候选状态。

## 当前20条结果的核对结论

- 20条样本 ID `01` 至 `20` 均有预测和主局部证据。18条主证据为 `text_exact`，2条为 `media_candidate`，分别是 `13` 和 `19` 的音频时段。全部局部证据中有40条 `text_exact`、59条 `media_candidate`、19条 `feature_only`，没有 `media_verified`。
- `13` 的对齐视觉特征全零，模型没有可用视觉证据，解释卡不得指定“模型依据的视觉关键帧”。音频主证据 `7.56–8.54s` 仅为候选，局部决策支持约为 `0.0098`。
- `19` 的音频主证据 `11.68–12.78s` 仅为候选，局部决策支持约为 `0.0084`。这两个短窗口都不能代表该模态的全部决策依据。
- `15` 的原文和 MP4 音轨覆盖范围不一致；文本证据仍可回指提供的 `raw_text`，但全部音频和视觉局部证据保持 `feature_only`，不能补造时段或帧。
- `07`、`18` 的原文超过模型50个 token 的输入上限；后续被截断文本没有参与预测，不能作为模型证据。

## 可直接用于论文的表述

“对附件4的20条无标签样本，模型同时输出情感强度、极性、三模态决策支持和局部证据。以模型预测类别的决策边际为目标，三模态作用程度采用完整模态组合的 Shapley 值，局部片段采用有效位置窗口遮挡效应。18条样本的主证据可精确回指所提供的原文；另2条样本的主证据为音频时段候选。由于所提供特征不含特征行至原始媒体的提取映射，音频时间和视觉帧均作为候选位置报告，不视为已核实的特征来源。附件4没有真实情感标签，不能据此计算测试集准确率或判定具体样本的分类错误原因。”

解释卡中建议逐项展示 `mapping_status`、特征位置、原文字符区间或候选媒体时间／帧、映射方法、局部遮挡决策支持及异常说明。对于 `feature_only`，媒体时间和帧号保持空值；对于 `media_candidate`，标题或图注显式标注“候选”。模态 Shapley 值说明的是冻结模型在指定组合规则下的行为，不称为现实因果作用或客观真实的最重要模态。

数据来源与复核依据：`outputs/attachment4/predictions_20.jsonl`、`outputs/attachment4/verification_20.json`、`outputs/attachment4/summary.json`，以及 `docs/attachment4_evidence.md`。若重新训练、调整推理或重新生成附件4结果，本说明中的数量和个例须重新核对。
